# ふたりの家事帖（合言葉・端末内暗号化版）

GitHub Pages上で配信する家事管理画面です。アクセストークン（PAT）を使わず、Web Crypto APIで家事記録を暗号化してブラウザ内に保存します。

## 利用手順

1. https://lifeislikeamelodies2.github.io/utari-kaji-web/ を開く。
2. 初回のみ、16文字以上の合言葉を2回入力して保管庫を作る。
3. 最初の家事一覧は空です。GitHubにログインして [非公開の元データ](https://github.com/lifeislikeamelodies2/futari-kaji-private/blob/main/kaji-state.json) をダウンロードし、アプリの「設定 → 読み込み」から取り込みます。取り込んだ後、端末に残った平文のJSONは削除することを推奨します。
4. 家事・完了履歴はその端末に暗号化保存されます。別端末へ移す場合は、設定で暗号化バックアップを書き出し、別端末の設定から読み込んでください。

## 重要な制約

- **自動同期はありません。** 同じ合言葉を別々のスマホに入力しても、記録が自動共有されるわけではありません。
- GitHub Pagesは静的なWeb画面の配信に使います。Privateリポジトリへ書き込みは行いません。
- 合言葉は保存せず、PBKDF2（SHA-256、60万回）で鍵を生成しAES-256-GCMで記録を暗号化します。ランダムsaltとIVを使います。
- ブラウザのサイトデータを消すと記録が失われます。定期的に暗号化バックアップを保存してください。合言葉を忘れると復元できません。
- アプリのコードとログイン画面は一般公開です。暗号化保存はGitHubの「2人限定ログイン」の代わりにはなりません。
- ブラウザや端末が侵害された場合、開錠中の情報までは保護できません。

以前のPAT直接入力方式は撤去しており、PATやGitHub認証情報を入力しないでください。

## ふたりの予定（暗号化共有）

アプリの「予定」ページでは、日付・任意の時刻・予定内容・対象者（私／相手／2人とも）・場所・備考を登録できます。ホーム画面の「ふたりで整える、心地よい暮らし。」には今日から約1か月先までの予定を表示します。

共有の仕組みには専用のサーバーやPATを使わず、GitHubの公開Issuesへの**暗号化された投稿**を使用します。予定は各端末の合言葉で暗号化保存され、さらに、Privateリポジトリで管理する共有設定キー（32バイト）で暗号化したメッセージをGitHub Issueとして投稿します。受け取る側は同じ共有設定キーで復号します。ブラウザはGitHub APIの公開閲覧機能だけを使用するため、GitHubのアクセストークンを保持しません。

**利用手順：** 両端末で従来の共有設定キーを登録し、アプリの「予定」で入力・保存します。保存直後は自端末のみに反映されるので、「GitHubで共有を確定」からGitHubのIssue作成画面を開き、本人のGitHubログイン後に **Submit new issue** を押します。相手の端末は開いた時と約5分おきに暗号化Issueを確認し、復号に成功した投稿だけを予定に反映します。編集・削除も同じ手順で変更投稿が必要です。GitHubの投稿画面が空白の場合は、GitHubアプリではなくブラウザでURLを開き、投稿本文が入力されていることを確認してください。

**制約・プライバシー：** 公開Issueの投稿者名・投稿日時、暗号文は第三者にも見えますが、予定内容や場所などの平文は投稿されません。暗号化済みIssueは削除後もGitHubの履歴に残る可能性があるため、機微な予定には注意してください。GitHubのIssue投稿を行わず「保存」しただけでは相手端末には反映されません。これは純粋なGitHub Pagesだけではサーバー側認証と書き込み処理を実行できないという構造上の制約です。
